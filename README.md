# Git Foundation Lab

I created a Git and GitHub learning project to practise documenting, tracking, and publishing work for my IT career portfolio. I added a .gitignore file so future clones share the same rules for excluding local and potentially sensitive files.

## Objectives

- Understand Git repositories, commits, and branches.
- Practice safe terminal navigation and Git workflows.
- Build a professional project record for future employers.

## Skills Demonstrated

- Used Git's staging area to select changes before creating commit.
- Connected the local repository to GitHub using the 'origin' remote and pushed the 'main' branch.
- Added `.gitignore` rules to exclude `.DS_Store`, `*.log`, and `.env` files.
